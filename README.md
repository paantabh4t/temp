# temp

A tiny command-line todo list, written in plain Node.js (no dependencies).

## Usage

```bash
node todo.js add "buy milk"
node todo.js list
node todo.js done 1
node todo.js undo 1
node todo.js edit 1 "buy oat milk"
node todo.js rm 1
node todo.js clear
node todo.js stats
```

## Tests

```bash
npm test
```
